# 2026-04-28 工作记录

## Bug 修复
1. **移动端侧边栏抽屉点击失效**：根因是 `.app-container` 有 `position:relative; z-index:1` 创建了 stacking context，导致内部 sidebar(z-index:50) 在根上下文中实际只有 z-index:1，低于外部 sidebar-backdrop(z-index:40)。backdrop 盖住了 sidebar，所有点击被 backdrop 拦截。修复：将 `sidebar-backdrop` 移入 `app-container` 内部，使其与 sidebar 在同一 stacking context。
2. **背景图片功能改为文件上传**：移除了 URL 输入框，改为上传按钮 + 清除按钮 + 状态文字。上传后自动压缩（最大1920px, JPEG 0.7质量）存为 Data URL，立即生效无需点保存。
