# 2026-04-28 工作日志

## SimpleGirlFriend 功能更新与Bug修复

### 新增功能
1. **快捷指令按钮**：在聊天输入框上方添加「🧠 /记忆」和「▶ /继续」两个按钮，点击直接触发，无需手动输入指令
2. **左侧边栏动态间距**：sp-section 改为 flex:1 动态高度，与 chat-list-section 共享剩余空间。聊天项少时 sp 区域自动变高
3. **分享URL压缩**：使用 CompressionStream(gzip) + base64url 编码，大幅缩短分享链接长度。v2格式自动兼容旧版v1/无前缀格式

### Bug修复
1. **手机端新建聊天无反应+输入框不可见**：
   - 根因：移动端 100vh 包含地址栏高度，导致输入框被推出视口
   - 修复：使用 100dvh + JS --app-height 变量双重保障视口高度
   - 额外：main-area 添加 overflow:hidden，chat-area 添加 min-height:0
   - newChat() 后 scrollIntoView 确保输入框可见

## SimpleGirlFriend PWA 改造

将单文件 HTML 应用改造为 PWA，新增文件：
- `manifest.json`：PWA配置，standalone模式，支持快捷方式（新建聊天）
- `sw.js`：Service Worker，预缓存静态资源，离线可用，自动检测新版本提示刷新
- `icons/`：8种尺寸图标（72/96/128/144/152/192/384/512）
- index.html 添加 PWA meta 标签（manifest、apple-touch-icon、theme-color 等）
- 添加安装横幅（`beforeinstallprompt` 触发，底部 toast 式提示用户安装）
- `action=new` URL 参数支持快捷方式直接新建聊天
