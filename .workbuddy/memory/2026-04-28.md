# 2026-04-28 工作记录

## Bug 修复
1. **移动端侧边栏抽屉点击失效**：根因是 `.app-container` 有 `position:relative; z-index:1` 创建了 stacking context，导致内部 sidebar(z-index:50) 在根上下文中实际只有 z-index:1，低于外部 sidebar-backdrop(z-index:40)。backdrop 盖住了 sidebar，所有点击被 backdrop 拦截。修复：将 `sidebar-backdrop` 移入 `app-container` 内部，使其与 sidebar 在同一 stacking context。
2. **背景图片功能改为文件上传**：移除了 URL 输入框，改为上传按钮 + 清除按钮 + 状态文字。上传后自动压缩（最大1920px, JPEG 0.7质量）存为 Data URL，立即生效无需点保存。
3. **全部按钮/Enter无法点击**：根因是 `<script>` 标签后的多行注释缺少开头的 `/*`，导致 `AI Chat - 全部逻辑（单文件实现）` 被当作JS代码执行，引发语法错误使整个脚本崩溃。修复：补上 `/* ==================================================================`。
4. **设置区OSS选项不可见**：`.settings-form.open` 的 `max-height:400px` + `overflow:hidden` 导致内容超出被截断，OSS checkbox 及下方设置无法看到。修复：改为 `max-height:70vh; overflow-y:auto`，允许滚动查看所有设置项。
5. **OSS导出404失败**：两个问题：(a) `getOssClient()` 缺少 `secure: true`，浏览器端必须用HTTPS访问OSS；(b) 用户Region填了`oss-cn-hangzhou`但Bucket在成都，SDK拼接出错误endpoint导致404。修复：添加`secure: true`参数；提醒用户Region必须与Bucket实际地域一致。

## 功能重构：移除阿里云OSS，替换为API同步
- **移除**：阿里云OSS SDK引用、OSS设置表单（STS/Bucket/Region）、OSS CSS样式、全部OSS JS函数（getOssClient/exportDataToOss/syncFromOss/toggleOssSettings/updateOssSyncBtn）
- **新增**：syncToken 设置项（代替ossEnabled/ossAppServer/ossBucket/ossRegion），云端同步功能
  - `syncToCloud()`：POST `https://poecurrency.top/api/v1/chat_sync`，Authorization: Bearer token，body: `{ data: base64 }`
  - `syncFromCloud()`：GET 同一URL，携带token，解析返回数据后执行导入
  - `applyImportedData(data)`：抽取公共的导入后UI刷新逻辑，供 handleImport/checkShareData/syncFromCloud 复用
- **UI变化**：导出按钮改为「同步到云端」+「导出文件」两个按钮，同步按钮改为「☁️ 同步」（从云端拉取）
- **分享数据**：syncToken 加入敏感信息清除列表（分享时删除）
- **兼容性**：loadData 中旧数据 ossEnabled/ossAppServer/ossBucket/ossRegion 不再迁移，自然淘汰
