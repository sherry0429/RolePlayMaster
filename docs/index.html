Desktop Presence

一台没有"界面"的桌面应用

透明无边框窗口紧贴内容：化身上方悬着最近的消息气泡堆和常驻输入栏， 不占屏幕、不打断手头的事，却随时都在。

待机：化身 + 常驻输入栏

圆形化身边缘渐隐、像一颗气泡浮在桌面。点输入栏直接打字，Enter 发送、Shift+Enter 换行，无需先打开任何窗口。

聊天：气泡堆悬在桌面

最近 3 个气泡常显在化身上方（每条最多 6 行），越往下越新、越清晰。开启说话人区分后，一个气泡 = 一个角色的一段话，人名直接用头像代替。

隐身：自动收纳

不需要时气泡堆自动收起，只留一条输入栏甚至只剩化身；按住任意区域即可拖到屏幕任意角落，窗口尺寸全程动态贴合内容。

Features

为"角色扮演"而生的一整套能力

从群聊、记忆到情绪动画，每个功能都围绕一件事：让角色更真实地陪在你身边。

桌面化身

透明无边框窗口，自动提取角色主色染遍气泡与按钮；化身边缘逐层淡出，像一颗会呼吸的气泡。

气泡堆 + 消息浮层

化身正上方悬着最近消息，点 ☰ 展开浮层回看历史，附带记忆 / 继续 / 拍照 / SP 快捷指令。

群聊聚合化身

多角色缩小成小圆、环形排布聚合进同一颗大圆；群聊回复按说话人拆成独立气泡，各带头像。

动态 System Prompt

人格设定版本化管理，可切换、可对比、可回滚；剧情演进，人格随之演化。

记忆压缩

每 300 句自动把全部聊天交给 AI 提炼摘要，融合进当前 System Prompt——聊得越久，角色越懂你。

AI 拍照

接入 ComfyUI 工作流，随时让角色"拍一张"当下的场景，收入专属相册。

情绪动画

上传约 2 秒的 AI 生成视频，自动抽帧拼成 sprite sheet；待机呼吸循环，情绪播完自动回待机。

数据完全属于你

全部数据存在本机 IndexedDB，支持导入 / 导出 JSON、云端同步由原生侧代发，密钥只留本机。

动态 System Prompt

会成长的人格设定

System Prompt 不是一段写死的文本，而是一份随剧情演进的"活档案"：结构化分节、版本化管理，编辑器里可以原文 / 对比双视图自由切换。

  • 版本化——每次演化生成新版本，可随时切回任意旧版本，旧版本之后触发更新则自动分叉
  • 自动压缩——超过阈值自动请 AI 提炼全部聊天为摘要并融合进人格，只携带增量上下文请求
  • 逐聊天隔离——每个聊天拥有独立的 System Prompt 与背景，互不串线
角色 & 群聊

建一个属于你的角色剧团

内置角色库开箱即用：勾选几位角色一键建群，他们会在同一颗聚合化身里各自开口、互相接话。

  • 角色管理——头像、人设、动画逐项编辑，支持导入 / 导出分享
  • 群聊面板——可视化建群、成员管理，多角色回复自动按说话人拆分
  • 接入任意模型——默认 DeepSeek，改 API Host / Key 即可切换任意 OpenAI 兼容供应商
情绪动画

让化身动起来

为角色上传约 2 秒的 AI 生成短视频（MP4 / WebM），应用自动抽帧、去重并拼成 sprite sheet。待机时循环播放呼吸感动画，聊天中触发对应情绪动画，播完自动回待机。

  • 零手工处理——上传即完成抽帧与合图，全程自动
  • 情绪驱动——惊讶、开心、不满……动画跟随剧情触发
  • 设置七大分页——桌面 / 聊天 / 接口 / 数据 / 记忆 / 图像 / 关于，各归其位

Under the Hood

轻、快、透明的技术底座

Tauri v2 透明窗口

transparent + 无边框 + 无阴影，macOS 启用 private API；窗口尺寸全程按内容动态计算，绝不大片透明区域遮挡桌面。

原生侧代发云端请求

云端同步由 Rust 侧 reqwest 代发，绕开 WebView 同源策略；基于 Tauri Channel 逐块上报真实下载进度。

同源复用 30 个业务模块

网页版 30 个业务模块原样移植到桌面版，流式请求、记忆压缩、群聊、相册逐行同源，修 bug 一次两端受益。

化身主色提取

32×32 canvas 上做 4bit 量化直方图，中心加权、明暗降权、饱和度抬升，角色主色自动染遍整套 UI。

窗口停靠与面板模式

开面板放大居中、关面板逐像素还原；拖动过就不会被拽回去，底边钉住、只向剩余空间生长。

数据本地优先

全部数据存于本机 IndexedDB，导入 / 导出 JSON、生成分享链接、云端双向同步，控制权始终在你手里。

安装并启动

首次启动，化身会自动停靠到屏幕右下角，并内置 8 个角色供你直接开聊，无需任何配置。

填入 API Key

右键化身 →「打开设置面板」→「接口」分页，填入你的 API Host 与 API Key（默认适配 DeepSeek，任意 OpenAI 兼容接口均可）。密钥只保存在本机。

开始对话

点化身上方的输入栏直接打字，Enter 发送；右键化身可以建群、切换角色、触发记忆与拍照。
