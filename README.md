# 角色扮演大师 / RolePlayMaster

### 项目介绍

本项目的目标，是构建一个简单易用，没有复杂功能的桌面电子宠物。

### 项目功能

它能够：

- 聊天，包括单聊/群聊
- 拍照（在设置了local comfyui / 接入硅基流动API的情况下）
- 自言自语（设置了自己找话题的情况下）
- 自我进化（随着聊天的进行，不断修正对自身，对用户的记忆）
- 动画响应（在录入动画后能够根据情况播放动画）
- 云端同步/拉取数据（在设置了云端服务器的情况下）
- 聊天相册，保存每个聊天过程中产生的图片

# Q/A
上述的功能都是开箱即用的，并且也可以由用户自己定制。

Q：为什么不用酒馆？

个人认为酒馆太重了，不管安装也好，使用也好，都需要接受大量知识并进行调优

Q：为什么只接Deepseek？

个人认为目前Deepseek进行角色扮演的活人感是最好的，蓝色大肥鱼遥遥领先。
