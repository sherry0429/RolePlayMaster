基本操作

  • 移动窗口：按住化身、气泡、消息浮层顶栏或面板标题栏拖动
  • 看消息 / 发消息：点击化身左上角的气泡（Enter 发送，Shift+Enter 换行）
  • 让 AI 继续：点气泡右侧的向下箭头
  • 打开菜单：在化身或气泡上右键
  • 记忆 / 拍照：右键菜单，或消息浮层下方的快捷按钮

数据存储

全部数据存在本机 WebView 的 IndexedDB 中（键名 aichat_data），结构与网页版完全一致， 但不与浏览器共享。需要通过「数据」标签页的导出 / 导入在两个版本间迁移。

已知边界

  • 不含重放功能
  • 桌面窗口透明，背景图设置不会绘制出来
  • 不支持浏览器 Web Push 通知
  • 拍照需要启用 ComfyUI 并提供工作流，否则只记录画面描述文本
